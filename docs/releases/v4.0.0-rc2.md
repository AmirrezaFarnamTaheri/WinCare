# WinCare v4.0.0-rc2

**Release candidate — not a stable or production-certified release.** For Windows 10/11 x64 and ARM64 testers.

## Highlights

- Redesigned native WinUI shell, Home, checkups, task discovery, troubleshooting and Power tools with a more restrained, consistent Fluent visual system.
- **Downloads:** direct HTTP(S) link handling, persisted jobs, actual byte progress, pause/resume/cancel, search and interruption recovery using the existing command dispatcher.
- **Files & storage:** bounded read-only folder/drive browsing, file-size inspection and safe Explorer handoff.
- **Processes:** per-process CPU and working-set readings, sorting, filtering, automatic refresh, protected-process restrictions and explicit confirmation before ending a task.
- Reliability and safety work across command admission, cancellation, Explorer restart recovery, native downloads, navigation, persistence and accurate success/failure reporting.

## Available packages

x64 and ARM64 MSIX installers, standalone executables and portable archives, matching development signing certificates, installer helper, source/oracle archives and `SHA256SUMS`. Verify downloaded checksums before installation.

## Important limitations and installation trust

**These packages use a self-signed WinCare Development certificate generated independently during each CI build. This is not a production-trusted code-signing identity.** For MSIX installation, explicitly inspect and trust the accompanying certificate using the supplied installer helper. Do not import a certificate from an unofficial mirror. Different builds may require different trust certificates. The portable binaries are similarly development-signed.

Some high-impact catalog commands remain intentionally unavailable. The experimental Guard service is not production-certified. Automated x64/ARM64 packaged runtime smoke and source tests are not a substitute for hands-on Narrator, keyboard, High Contrast, text scaling, installation/upgrade or destructive-operation verification.

Download URLs with signed query strings may be retained in local queue records; avoid secret-bearing links. Cross-process download ownership is not yet fully transactional, and do not assume downloaded files receive Mark-of-the-Web metadata. Do not run software downloaded from untrusted sources.

This prerelease is for evaluation. Report issues at [WinCare Issues](https://github.com/AmirrezaFarnamTaheri/WinCare/issues); report vulnerabilities using [private vulnerability reporting](https://github.com/AmirrezaFarnamTaheri/WinCare/security/advisories).
