Admission semantics

Safe: one-click execution. Moderate: lightweight explicit confirmation. Destructive: successful preview plus a current, single-use ApprovedMutationPlan. Invalid risk metadata is rejected before handler execution.

Power-user inspection and diagnostics

Parallel probe runner

  • system, storage, and security run with bounded concurrency.
  • Results preserve request order and isolate individual probe failures.
  • Windows Update readiness reports independently in the background.

Rust core engine

  • C-ABI system snapshot and safe temp-clean primitives.
  • Bundled wincare_core.dll ABI is validated by the packaged smoke path.
  • Temp cleanup skips Windows reparse-point directories and junction targets.

Activity and evidence

  • Activity journal records admitted command lifecycle.
  • Unavailable telemetry is displayed as unavailable rather than a fabricated healthy value.
  • Generic rollback is not promised without an executable compensator.
