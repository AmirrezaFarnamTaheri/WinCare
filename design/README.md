# WinCare V5 design assets

This folder contains target-native design deliverables for the graphical console.

- `WinCare-V5-GUI-Preview.svg` / `.png` — overview-screen visual specification.
- `WinCare-V5-Logo.svg` / `.png` — scalable product mark.
- `WinCare-V5-Tokens.json` — portable color, spacing, radius, and typography tokens suitable for design-tool import or handoff.

The executable WPF source is under `src/WinCare/Data/Gui/WinCare.MainWindow.xaml`. The preview is a design reference, not evidence that WPF was rendered in this Linux build environment. See `docs/Design-System.md` for accessibility, component, and interaction rules.
