# WinCare

Native Windows 10/11 maintenance and diagnostics application using WinUI 3, .NET 8 and a Rust core. People and technicians inspect Windows, maintain it, review changes and recover from problems.

The 259-command catalog and existing dispatcher/integrations define functionality; visual concepts add no capabilities. The release candidate's promotion gates remain in VALIDATION.md.

Evidence collection is distinct from a health verdict. Commands retain risk/admission rules. Activity reports actual outcomes. Undo requires an executable compensator. Remote installation stays browse-only without an approved catalog trust root.

The user selected the Instrument Bench, System Atlas, Focus and Care Board hybrid. DESIGN.md records the visual system and UX-CONTRACT.md its behavior. Runtime contracts outweigh generated concept copy.

Product evidence: README.md, docs/Architecture.md, SECURITY.md, VALIDATION.md, command catalog and application services. docs/Screenshots.md distinguishes historical captures from concepts.
